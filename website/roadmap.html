Roadmap

What is live, and what comes next

Last updated 23 October 2026

HoneyBeeSMP ships in small, tested updates. This is the honest version: what is already on the server, what we are working on now, and what we want to do after that. Dates are not promises, and the order can change when testing or player feedback says it should.

Done In progress Planned
Done

Live now

Already on the server and in the pack.

Pack 1.2.3

86 mods on Minecraft 1.21.1 NeoForge, built around Create 6 and the addons that make a factory worth running.

A world worth exploring

Terralith and Tectonic terrain, YUNG’s structures and Moog’s additions, pregenerated to a 5,000-block radius.

Claims that hold

Open Parties and Claims gives you 400 chunks, 8 forceloads, 3 anchors, parties of eight and groups for sharing access.

Voice and map

Simple Voice Chat for proximity voice in game and Discord, plus a BlueMap live map of the world.

Discord that connects

Mc2Discord bridges #minecraft-chat both ways. #bugs and #suggestions are forums with pinned templates.

Staff audit log

Message edits and deletes, joins, role changes, bans and channel changes post to the staff-only #logs channel.

Backups and restarts

Automatic twice-daily world backups to Google Drive, plus a daily restart at 04:00 UTC.

Rules and website

Public rules, the full pack list, privacy and cookie pages, and a live player count on the home page.

In progress

Up next

Being tested or finished now.

Modrinth listing approval

The pack is in Modrinth’s review queue. Once it clears, the public listing and one-click install are the same route.

Monthly update cycle

Move from ad-hoc pack changes to a monthly dev-to-live update, with a changelog and a compatibility pass before it reaches the live server.

Performance baseline

Run Spark under real load, record a baseline, and tune view distance, entity limits and forceload behaviour from data rather than guesses.

Restore drill

Restore the latest backup into a test world and confirm the world, configs and player data all come back.

Client QA pass

Test chat prefixes, the new keybind defaults and both directions of the Discord bridge with a real client and an alt.

Setup automation

Move the pinned #bugs and #suggestions templates into /setup, so a rebuild recreates them instead of relying on manual posts.

Planned

After that

Wanted, but not scheduled yet.

Public changelog

A page per pack release: what changed, what was removed, and whether you need to update the pack.

Player feedback loop

Review #suggestions on a regular cadence and publish what made the roadmap, what is being tested and what is not going ahead.

Community events

Build nights, factory tours and a shared spawn or station project, once the update cycle is predictable.

More Create content

Evaluate new Create addons and recipe changes each cycle, with performance and compatibility tested before they join the pack.

Monitoring and alerts

Watch backup age, disk space, the live port and failed services, and alert staff before players notice a problem.

Public status page

A small status page for server availability and the latest successful backup, so there is one place to check.

How we ship. A change goes to the dev server first, gets tested with a real client, then moves to live. If an update needs a restart, it waits for a quiet moment rather than interrupting players. The roadmap is reviewed whenever the pack changes.
