Getting started

Four steps and you are building

The server runs a modpack, so it needs to be installed before you can connect. Modrinth and Prism Launcher both do that for you, and both keep the pack up to date, so nobody is ever on different mods.

Get a launcher

Install Prism Launcher or the Modrinth App. Either one works, and both are free.

Install the pack

Point it at HoneyBeeSMP on Modrinth and hit play. The mods install themselves.

Connect

Launch the profile it makes and join, or connect straight to play.honeybeesmp.co.uk on port 25566.

Claim and build

Open your map — M by default — and claim the chunks you want to keep. You get 400, which is a very large base.

Not sure where to build? The live map shows the world, everything built so far, and who is online right now.

What is here

Built for people who like making things

Not a survival server with some automation tacked on. The whole server is arranged around Create, so the mods fit together and a big factory is a normal thing to run.

Create, and the addons that matter

Create 6 with Create Addition, Copycats+, Central Kitchen, Ore Excavation and Compression, plus Numismatics so the economy has a real currency.

Claims that do their job

Open Parties and Claims gives you 400 chunks, parties of eight, and groups so you can hand the right people the right keys.

A world worth building in

Terralith and Tectonic for the terrain, YUNG's for the mineshafts, caves, fortresses and the End, and Moog's structures on top.

A pregenerated world, so you never wait

The world is pregenerated out to a 5,000 block radius before you arrive. No chunk stuttering while you try to start a factory.

Proximity voice

Simple Voice Chat puts you with the people actually standing near you. It works in game and in the Discord.

Fast enough for big builds

Sodium, ImmediatelyFast, Lithium, ModernFix and FerriteCore, with Spark on the server so lag can actually be traced.
